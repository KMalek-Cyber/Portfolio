# KLIMANE MALEK — Cybersecurity Portfolio

Portfolio personnel statique, pensé pour GitHub Pages.

## Mise en ligne sur GitHub

1. Crée un nouveau repository sur GitHub, par exemple `portfolio`.
2. Décompresse ce dossier.
3. Envoie **tous les fichiers** du dossier dans le repository.
4. Va dans **Settings → Pages**.
5. Dans **Build and deployment**, sélectionne **Deploy from a branch**.
6. Choisis `main` et `/ (root)`.
7. Enregistre.
8. GitHub te donnera l'adresse publique du portfolio.

## Avant de publier

- Remplace `CV_Klimane_Malek.pdf` par ton vrai CV PDF dans le dossier racine.
- Dans `index.html`, remplace les deux liens `#` de LinkedIn et GitHub par tes vrais profils.
- Vérifie le numéro de téléphone et l'adresse e-mail.
- Si tu veux ajouter des captures de projets, place-les dans `assets/` puis ajoute-les dans les cartes projet.

## Structure

```text
portfolio/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    ├── profile.jpg
    └── favicon.svg
```

Aucun framework, aucune installation et aucune base de données : le site fonctionne directement avec GitHub Pages.

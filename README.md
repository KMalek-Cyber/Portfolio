# Malek KLIMANE — Portfolio Cybersécurité

Portfolio statique publié avec GitHub Pages.

## Fichiers
- `index.html` — page principale
- `style.css` — identité visuelle
- `script.js` — interactions
- `assets/` — photo, certificats et dossier du projet BTS

## Publication
GitHub Pages peut publier directement depuis la branche `main` et le dossier `/ (root)`.
